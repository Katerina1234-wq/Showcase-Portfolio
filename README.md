# 3D Interactive Portfolio

## Project Overview

This project is a modern, **3D interactive portfolio website** built to showcase my work, technical skills, and creativity in an immersive and engaging way.  
The experience combines smooth animations, real-time 3D elements, and dynamic project presentation to create a visually rich and memorable user journey.

### Project Goals
- Present personal projects and technical skills in a compelling, modern format  
- Use 3D models and animation to enhance storytelling and user engagement  
- Maintain high performance and full responsiveness across all devices  


##  Tech Stack

| Category | Technology |
|--------|-----------|
| Frontend Framework | **Next.js** (App Router) |
| 3D Graphics | **Three.js** |
| Styling | **Tailwind CSS** |
| Animations | **Framer Motion**, **GSAP**, Three.js Animations |
| 3D Assets | **.glb models** (created in Blender) |
| Deployment | **Netlify** |
| Version Control | **GitHub** |


##  Key Features

###  1. 3D Model Integration
- Import and render optimized 3D models from Blender  
- Interactive camera motion and orbit controls  
- Performance-optimized assets for fast loading  

###  2. Smooth Animations
- Page transitions and UI animations with Framer Motion  
- Subtle hover, scroll, and micro-interactions  
- Animated 3D scenes including rotating and floating objects  


###  3. Dynamic Project Showcase
- Interactive project cards  
- Animated project previews and transitions
